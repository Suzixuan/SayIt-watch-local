# SayIt Watch icon 0.1.0-candidate.1

- Status: candidate
- Parent: none (first icon exploration)
- Scope: concept preview only; not wired into Android resources
- Approval: pending user visual selection

## Intent

Explore an independent visual identity for the Watch companion: press on the wrist, capture speech, and send it to the PC. Avoid copying the upstream SayIt wordmark or microphone icon.

## Variants

- A: voice pulse crossing a bridge
- B: waveform transferred to a desktop
- C: abstract continuous audio path
- D: OLED pulse with recording indicator
- E: Watch-to-PC endpoint link
- F: speech capsule and insertion caret

## Inherited locks

- Circular Wear OS mask safe area
- Legible at small launcher sizes
- No text or letters inside the icon
- No change to the approved app UI or runtime behavior

## Next step

After the user selects one direction, redraw it as a precise adaptive-icon foreground/background asset and verify at launcher size on the physical Galaxy Watch 7.
